# 后处理轮：温度、权重平均窗口与 train-only bigram 辅助模型（2026-09-28）

本轮先把已有的后处理配方收尾（阶段 A），再检验一个新的信息源——只用课程 `train` 统计的 bigram 辅助模型（阶段 B）。全部只用 `train` 构建统计量、用 `validation` 选方案，只跑 CPU FP32，**没有重训学生**；test 在所有选择与冻结完成之后评了一次，**仅用于课程登记填表**（见 §4.5），未参与任何选择。

下面除标注「官方」外都是**探针 validation BPB**，包含在固定小网格上取最小值的选择偏差（已知同配方跨种子差约 0.0022，本轮主要效应与之同量级）；`probe_seconds` 包含全部候选，**不是**交付推理时间。

## 2. 阶段 B：train-only bigram 辅助模型

表只用固定 tokenizer 编码后的课程 `train` 文本构建（**不打开 validation/test 的 target**）：编码后 **3,613,343** 个 token（`train_utf8_bytes` 10,951,562，SHA `c58d555a…`），bigram 计数后按 train-only unigram 先验平滑，固定强度 **β=32**；先验带 add-one 伪计数（2048 个词表 token 中有 **84 个在 train 中一次都没出现**，纯 MLE 会留下 0 项；这 84 个 token 在 validation 中作为 target 出现 0 次，故不影响任何 BPB 数字）。表为 `2048×2048 float32` = **16,777,216 字节（16 MiB）**，已观测 bigram 对 **298,024**，最小概率 `7.78e-11 > 0`，行归一化误差 < 1e-5。构建成本：tokenize **9.77 s** + 建表 **0.047 s**。β 与平滑方式未在 validation 上搜索。

固定 α 探针（与 A3 完全相同的学生分布 k33 + T=1.19）：

| α | 0 | 0.005 | 0.01 | **0.02** | 0.05 |
|---|---:|---:|---:|---:|---:|
| BPB | 1.4665408 | 1.4654146 | 1.4650006 | **1.4647974** | 1.4663321 |
| Δ vs α=0 | — | −0.0011262 | −0.0015402 | **−0.0017434** | −0.0002087 |

α=0 校验同样相差 `1.0e-7`；0.02 最优、0.05 反弹，最优点在网格内部。相对 A 最终件增益 **`0.0017435`**，相对既有交付件的官方值低 `0.0022082`；峰值工作集 **1.844 GiB**（探针口径，含 5 个候选），墙钟 96.2 s。

| 方案 | 最佳 | 探针 BPB | 增益 | 额外推理开销 |
|---|---|---:|---:|---|
| A3 copy | α=0.005 | 1.4654956 | 0.0010452 | 需逐窗口构造 unigram 累加缓存 |
| **B bigram** | α=0.02 | **1.4647974** | **0.0017435** | 只需一次查表 |

两者都过了各自门槛，但 bigram 增益更大（1.7 倍）且推理开销更低，**故只把它实现为交付 predictor**，copy 保留为探针记录。计划中「达到门槛才考虑一个简单自适应混合」**决定不实施**：自适应系数需再在 validation 上选一轮，会把选择偏差叠加到本轮唯一的效应上。这是取舍决定，不是负结果。

## 6. 结论与限定

**可以得出**：在同一 40k 日程与同一批 checkpoint 上等权窗口越宽越好（k33 < k25 < k17 < k13），但增益收窄；纯权重/温度改动未越过 0.0005 阈值；train-only bigram 是有效的新信息源（α=0.02 把探针从 1.4665408 降到 1.4647974），α=0 与温度探针逐位校验通过、交付实现与探针逐位一致，说明增益来自 bigram 本身；bigram 增益大于同为 ≥0.0010 门槛的 copy，且推理只需一次查表；交付件通过全部三项资源门槛与六项审计。

**不能得出**：`0.0022082` **不是可泛化的提升**——单种子（seed 17）、在 5 点 α 网格上取最小值，已知同配方跨种子差约 0.0022，**选择偏差与效应同量级**，且没有任何不确定性估计；α=0.02 不是最优权重（0.05 反弹，网格外未测、不得外推）；β=32 与 add-one 先验未与其他取值比较；增益不能归因于「学到了语言结构」（只统计相邻 token 对，本轮无消融）；不能把 validation 与任何 test 口径的数值互相比较；不构成对 copy 或连续缓存的否证（阶段 C 完全没跑）。
